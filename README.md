### 🔐 Nikash — Hardware Web3 Verifier

An **ESP32-based hardware verifier terminal** combining NFC, embedded cryptography and blockchain infrastructure.

Key technologies:

- ESP32 + ESP-IDF
- FreeRTOS
- PN532 NFC
- Keccak-256
- secp256k1 ECDSA
- RLP encoding
- EIP-155 transaction signing
- Ethereum RPC
- Hardware-secured key handling

**C++ · Embedded Systems · NFC · Cryptography · Web3**
