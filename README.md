My work has taken me from **industrial robotic automation at IIT Bombay**, to **CNC heat-sealing pipelines for soft robotic actuators**, to founding **Dhruva Labs** — building hardware that puts blockchain assets on a physical tap-to-verify smart card.

# 🏭 Research & Engineering

## IIT Bombay (IEOR) — Industrial Robotics & Automation

Built an **Industry 4.0 factory automation system** on Dobot robotic arms:

- 🤖 Trajectory planning optimization, cutting real-time palletizing latency
- ✋ MediaPipe hand-tracking evaluation under high-occlusion conditions for gesture-based control
- 🔌 Hardware–software integration across microcontrollers, sensors, and robotic systems
- 🐍 Built **`dobotexpress`** — an open-source Python interface for controlling Dobot robotic arms

---

## 🔥 WIRED Lab, IIT Bombay — CNC Heat-Sealing for Wearable Haptics

Developing the software and hardware pipeline for **multilayer soft robotic actuator fabrication**:

- 📐 Python pipeline that processes DXF files directly — no slicer software needed
- ⚙️ Dynamic G-code generator with layer optimization for multi-stage heat-sealing
- 🖥️ Desktop GUI for DXF visualization + live temperature, pressure, and workflow control
- 🧤 Fabricated TPU actuators for wearable haptics — wristbands, gloves, elbow sleeves

---

## 🃏 Dhruva Labs — Hardware-First Web3

An **ESP32-based smart card platform** turning digital asset ownership into a tap.

- 🔐 Embedded Ethereum client — Keccak-256, secp256k1 ECDSA, RLP encoding, EIP-155 signing
- 🗝️ Hardware-secured key storage and on-device address derivation
- 📡 Verifier workflows + blockchain communication layer for tap-based validation
- ✅ Smart contract actions triggered by tapping a physical NFC card
